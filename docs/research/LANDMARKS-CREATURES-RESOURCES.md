# Landmarks, creatures and resources

Research and content proposal · 2026-10-20 · original **Subnautica**, not its sequels.

**Recommendation:** build recognizable *habitats*, not evenly scattered objects. Each region needs a distant silhouette, several different places beneath it, resident life doing something legible, and materials whose appearance teaches a repeatable search rule. A rewarding detour can yield knowledge, convenience or a useful view; it need not yield another compulsory recipe.

### Patterns worth transferring

1. **Three scales of place.** A region silhouette establishes bearing; a wreck, tree, arch, colony or cave mouth supplies a destination; nests, outcrops and scannable details reward close inspection. Landmark *hierarchy* matters more than making every object equally conspicuous. The inaccessible prototype ship attracted players by silhouette alone. [P2]
2. **Materials teach a search grammar.** “Break this rock type,” “look beneath this plant,” “search this animal's scrap pile” are learnable verbs. Current limestone yields copper/titanium, sandstone gold/lead/silver, shale gold/lithium/diamond; their distributions overlap. Transfer context and recognition, not the false rule that each mineral has exactly one biome. Cleveland's 2015 essay is design intent, not today's distribution table. [P1, O1–O3]
3. **Most life does not attack.** Prey, background schools, slow observers, sessile colonies and occasional huge benign animals make threats exceptions. Role overlap economizes content: a predator can also expose a useful resource. There is no reason to add a leviathan or a helper to every region. [B1–B10, P3]
4. **Wrecks offer several payoffs.** Visible fragments outside reward initial arrival; interior routes add plans/data, furniture and human context. They make searching a place productive beyond mining. Scanning completed technologies can still return titanium. Siltwake should use its existing plan/tech-record system, not introduce an unbudgeted fragment currency. [R1–R4]
5. **Light reorganizes attention.** Sunlit crowns, shaded roots, glowing night organs and deep permanent darkness can give the same geometry different readings. Preserve major bearings and retreat cues; reserve moving warnings for actual behavior. Constant glow everywhere destroys the contrast. [B2, B4–B9, C6]

## Practical density and progression targets

**No inspected primary source publishes an optimal POI/km² or regular landmark spacing.** Wiki inventories illustrate uneven, nested density: Safe Shallows lists eight wreck sites and two geysers across disconnected patches; Kelp Forest lists two large wrecks and a lifepod plus cave entrances; Grassy Plateaus lists eleven wreck sites, two lifepods and four Jellyshroom entrances across four areas. These are inventory counts, not exhaustive unique attractions, biome-area measurements or per-km² evidence. [B1–B3]

Use the following **Siltwake tuning hypotheses**. A discovery cluster is a distinct destination/action or meaningful observation, not each rock, building mesh, clue console or nearby resource pickup. A dish with a log and crust patch counts once. Nested POIs must not inflate completion or density totals.

## Concrete regional content proposals

These are additions/compositions, **not specification changes**. **C = cheap:** place/scatter existing art, existing species or a proven animation/interaction template; still needs layout and validation. **E-art / E-behavior = expensive:** new distinctive mesh/rig or new behavior/interaction. Costs describe *incremental* work: reusing S4's threat is cheap after S4 composition, not a claim that threat production is free. New names below are working labels, not new inventory IDs.

Use richer cel shading with broad coloured planes, readable ribs/edges, atmospheric separation and controlled emissive accents. Mechanical landmarks retain precise repeating dimensions; biology uses organic asymmetric profiles. No copied mushroom forests, glowing blood-vines, giant fossil set pieces or stranded starship designs. Reuse Siltwake's existing ribs, tethered crowns, survey hardware, layered minerals and species. Each region lists **three landmark compositions and 3–4 creatures**; repeated species are deliberate habitat continuity.

## Economical first pass and validation

First **dress and connect the existing destinations**: place resident groups around sources, vary existing structures, compose return views, and attach the two side rewards to existing geometry. Repeated rocks, pylons and building meshes do not become content merely by being numerous. New expensive candidates are the floaters, shore buttons, silt combs and seam pickers; they can be staged after the linked world works. None of these new assets is a prerequisite for collecting the existing material stock.

Validate one representative route per region before multiplying scatter:

- Can a new player identify the region from a silhouette, name two local places and return using a learned bearing, including at night/depth?
- After one collection, can they infer a second source from habitat/animal behavior, without waiting for a drop or following an undiscovered coordinate pin?
- Is there peaceful life between threats, with source availability and retreat information that remain readable if a school/sail is absent?
- Does a detour repay time with a useful scan, existing plan, service, material quantity or navigational shortcut? Is optional reward stock reflected in the existing ledger?
- Do warning animals, visible fields and actual harm agree? Are sources approachable before the upgrades they fund, with recovery paths and useful return margins?

Measure empty travel, stop frequency, material-search recall and return margins with ordinary input. Tune spacing against actual speed/fog; shorten empty legs before adding filler. Existing S4/S9 tests and this report establish neither human enjoyment nor ten-hour pacing.
