Both versions contain the same island, reef arch, refuge pod, scout, coral, kelp and fish. Voxel uses stepped volumes; cel-shaded uses curved geometry, banded lighting and ink outlines.

All art is procedural, rendered in Babylon.js. No pre-rendered or AI-generated images. No mining, survival, interiors, resource economy or large-world performance is demonstrated here.
